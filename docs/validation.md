## Windows 人工验收

① 解压工作流产物并直接运行 `relic_arpg.exe`，确认中文完整、主菜单布局正常、窗口可缩放。

② 进入试炼场，移动、沿墙闪避、绕过障碍、移动鼠标检查角色朝向与镜头；验证空格冷却，确认鼠标停在菜单区域时无意外操作。

③ Esc 暂停，打开设置，调整音量并试听，切换全屏后返回。恢复时角色与镜头继续正常工作。

④ 移动到便于辨识的位置并保存，退出重开后选择继续；确认位置一致。再测试贴墙保存、保存并回菜单、保存并退出。

⑤ 在 1280×720 和 1920×1080 检查排版。记录 Windows 版本、CPU、GPU、驱动、分辨率和实际帧时间。当前结果仅用于 M0 基础体验，M1 才开始怪群性能验收。
