历史 M2 已完成战斗、随机装备、背包仓库和整备循环。当前存档基线为独立 Hub 与五模块 Resource 检查点；仅 Hub 保存，旧 JSON 和旧探险恢复已退休。历史阶段结果不替代本卡验证。

## 本次要做的任务

① 新增一名墓园首领，采用独立场景与数据。至少三种可读招式：近距挥击、锁向冲撞、落点危险区，包含预警、执行和恢复期。

② 生命降到明确阈值进入第二阶段，调整招式组合与节奏；阶段切换只执行一次。为所有招式保留闪避或走位空间。

③ 提供首领血条、进场触发、战斗结束、死亡清理与房间出口状态；替换首领房精英占位并接入现有通关流程。

④ 单体战斗验证命中回能、闲置回能、药剂与技能循环；三套构筑均能持续战斗。首领掉落先复用精英通用池，专属来源由 P2_Task7 接入。

## 验收标准

① 正常入口找到并击杀首领后，血条隐藏、危险区清理、出口开放且通关只计一次。

② 三个招式、阶段阈值、暂停、死亡重开、提前撤离均可实际运行；预警与伤害区域一致。

③ 三套构筑分别在无小怪补给条件下持续战斗并完成击杀，记录装备、等级、耗时和能量最低值。

④ 在前摇、第二阶段切换后和首领死亡后分别撤离，验证动作清理与奖励一次性；回 Hub 保存重启保留长期进度，下一趟首领按新探险建立。

功能验证通过 `python tools/verify.py --godot <引擎路径>` 执行；新增用例需要实际运行到完成标记。涉及显示、声音和操作的标准按可见运行与试玩记录验收，历史结果不能代替本次验证。
