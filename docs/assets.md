# 资产交付规范

M0 使用原生几何体与程序短音占位，正式美术方向待确认。当前比例为 1 单位 1 米，Y 向上、-Z 为角色前方、根节点位于脚底，人形高度 1.8 米。碰撞胶囊半径 0.4 米，视觉子树独立替换，武器挂点位于 `VisualRoot/WeaponSocket`。

正式模型使用 `.glb`，源工程放 `source_art/`，引擎文件放所属功能的 `assets/`，通过包装场景配置碰撞、材质与脚本。静态素材与角色均保持原点和比例约定。文件采用 `主体_用途_变体`，例如 `skeleton_melee.glb`。

| 类别 | 初始目标 |
| --- | --- |
| 模型 | 玩家 5,000～10,000 三角面，普通怪 1,500～4,000；按实测调整 |
| 动画 | 原地动作，idle/run/attack_01/whirlwind_loop/dodge/hit/die；当前尚未制作 |
| 地图 | 地面模块 4×4 米，1 米网格，门宽暂定 4 米 |
| 贴图 | 普通怪优先单材质槽，512 或 1024 贴图 |
| 图标 | 256×256 透明 PNG，缩至 64～96 像素仍可辨认 |
| 界面 | 原规划设计基准 1920×1080，M0 默认窗口 1280×720；容器布局 |
| 字体 | M0 使用中文系统字体候选；D3 确认随包中文字体及许可证 |
| 音频 | 短音效 WAV，长音乐 Ogg；当前仅程序提示音 |

交付备注：`资产ID｜名称｜作者或来源｜源文件｜引擎文件｜规格｜绑定与动画｜材质｜许可证｜状态｜导入验收结果`。引入外部素材前将来源记入 `asset_sources.md`。
