## 验收标准

① 达到 3 构筑、6 主动技能、10 被动、18 底材、24 词条、6 独特、6 普通敌人、4 精英修饰、1 首领、12 房间模板和3档难度。

② 三套构筑各完成一趟完整区域，至少一套连续完成三趟并覆盖三档难度；操作与当前 UI 文本一致。

③ 跨模块保存场景全部恢复并继续战斗；物品与奖励无重复，随机地图与下一次随机结果一致。

④ 完整自动验证、Windows 导出与导出包启动通过；实际画面与手感按已执行内容记录，遗留项交给 D3。

功能验证通过 `python tools/verify.py --godot <引擎路径>` 执行；新增用例需要实际运行到完成标记。涉及显示、声音和操作的标准按可见运行与试玩记录验收，历史结果不能代替本次验证。
