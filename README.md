# Relic ARPG

单机 3D 俯视动作刷宝项目。当前为 **M2 刷宝原型**：旋风近战、随机装备、雷霆旋风构筑、整备与完整探险存档已经接通。正式美术仍为 Godot 几何体占位，Demo 的其他构筑、随机墓园、首领和发行打磨尚未完成。

## 启动与操作

用 **Godot 4.7.2 标准版**打开 `game/project.godot`，运行项目。Windows 键鼠为首个验证平台，当前使用兼容渲染器。

| 操作 | 按键 / 入口 |
| --- | --- |
| 移动 / 瞄准 | WASD 或方向键 / 鼠标 |
| 普攻 / 旋风 | 鼠标左键 / 右键；旋风耗尽后松开再施放 |
| 闪避 | 空格 |
| 背包与换装 | I；选择物品，左右查看词条与当前装备，点击穿戴 |
| 拾取装备 | 靠近后 E；重叠候选按 Tab 切换 |
| 金币与材料 | 两米内自动拾取 |
| 撤离整备 | T，或背包里的撤离按钮 |
| 保存完整进度 | F5；暂停菜单也可保存、保存并返回、保存并退出 |
| 暂停与设置 | Esc |

新建角色从整备界面开始，点击“出发”进入 48 怪固定场地，包含近战、远程、冲锋与一名精英。清怪获得经验、金币、材料与装备，穿戴即时改变伤害、范围、攻速及触发机制。清场后拾取战利品，按 T 撤离；已完成的探险使下一趟难度提高。提前撤离或死亡结束本次挑战，保留已拾取装备与成长，未拾取物品随本次探险回收。

前三次清场依次在最后击杀位置奖励雷鸣指环、余烬锁甲、噬能护手，仍需手动拾取穿戴。三件分别提供暴击连锁、感电死亡爆炸和命中/击杀回能；独特装备也可由精英随机掉落。独特装备不是自动穿戴奖励。

背包 40 格、仓库 120 格；仓库转移与出售在据点操作。六个装备槽为武器、头部、胸甲、手部、足部、戒指。锁定防止误卖和丢弃；满包可以交换同槽装备，卸下需要空位。过滤可选全部、魔法以上、稀有以上，隐藏的地面物品继续保存在探险中。材料暂作持有与掉落资源，消耗服务在 D1 加入。

## 存档

Godot `user://session.json` 保存角色、背包、仓库、穿戴、等级、难度、地面掉落、敌人生命与行动阶段、感电、弹体、冷却以及独立随机序列。`settings.cfg` 独立保存设置。Windows 默认目录：`%APPDATA%/Godot/app_userdata/Relic ARPG/`。

存档版本为 2；旧版位置存档进入新角色整备流程，下次保存升级。保存前同步结算完当前有限触发链；导航路径重算，纯视觉特效重建或结束，按键意图由玩家重新输入。出发与撤离自动保存，探险中可随时 F5；强制终止后从最后成功保存恢复。

## 验证与导出

```bash
python tools/verify.py --godot /path/to/godot
```

在临时用户目录执行编辑器导入、主菜单启动、M0/M1/M2 实际场景回归。失败、脚本错误与未出现完成标记均导致非零退出码。测试不会覆盖玩家存档。验证范围与实际结果见 `docs/validation.md`。

安装同版导出模板后：

```bash
godot --headless --path game --editor --import --quit
godot --headless --path game --export-release "Windows Desktop" ../builds/windows/relic_arpg.exe
```

先创建 `builds/windows/`。Windows 产物为内嵌资源的 `relic_arpg.exe`；工作流成功后可下载 `relic-arpg-m2-windows`。工作流会运行规则回归、实际导出，并独立启动导出包进入 M2 探险。

## 保留的 M1 测试入口

`world/maps/combat_arena.tscn` 仍可单独运行：1/2 切换测试预设，R 重开 24 怪，F6 生成 100 怪。正式 M2 入口关闭这些调试快捷键，构筑来自真实穿戴。

```bash
godot --headless --path game res://debug/stress_test.tscn -- --stress-seconds=180 --preset=thunder
```

此压力场景验证 M1 战斗，未包含 M2 地面掉落。无窗口数据覆盖 CPU 与物理；目标机画面、中文字体、音效听感、手感和 GPU 性能仍待实机验证。每趟时长与经济曲线尚未经过玩家试玩调优。
